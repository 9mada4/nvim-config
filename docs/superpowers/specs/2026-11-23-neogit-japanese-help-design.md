# Neogit 日本語説明・選択実行 設計

## 目的
Git 操作そのものに不慣れなため、Neogit のポップアップで「押したら何が起きるか」を
実行前に日本語で確認できるようにする。あわせてステータス画面上部ヒントが
スクロール後に見えなくなる問題を直す。

## ゴール
- ポップアップ（`?` のヘルプポップアップ含む）でカーソル下の項目を「選択中」として強調表示する。
- `<CR>` / `<Space>` で選択中の項目を実行する（Neogit 本来のキーを送るだけ）。
- `?` で選択中の項目の日本語説明（何が起きるか・注意・対応 git コマンド）をフロート表示。
- ステータス画面で 1 行目に戻ったら上部ヒントが再表示される。

## 非ゴール / アンチゴール
- Neogit の既存キー動作（キー単押しで即実行）は変えない。
- Neogit 本体のファイルは編集しない。内部 state を書き換えない。

## アプローチ
- 採用: カーソル位置から項目を判定し、強調と `<CR>`/`<Space>`/`?` をバッファローカルに追加。
- 不採用: 選択専用モード（全キーを差し替え、更新で壊れやすい）。
- ヒント修正: 採用 `WinScrolled`/`CursorMoved` で `topline==1` のとき `topfill` を戻す。
  不採用 winbar（1 行しか出せない）。

## 判定方法
- スイッチ/オプション/コンフィグ: `popup.buffer.ui:get_interactive_component_under_cursor()`。
- アクション: Grid で横並びのため、行テキスト中の各アクションの「キー + 説明」開始列を求め、
  カーソル列以下で最も右にあるものを選ぶ。
- 実行は `nvim_feedkeys(key, "m")` で Neogit のマッピングを呼ぶ。

## 説明データ
`lua/config/neogit_help_ja.lua` に表で持つ。アクションは `ポップアップ名 → キー`、
引数は `--flag` 名。初期範囲は Commit / Pull / Push / Stash / Help（判断: Claude）。
未登録項目は英語説明 +「説明未登録」を表示。
